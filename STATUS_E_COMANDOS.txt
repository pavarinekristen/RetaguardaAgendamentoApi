9. SITUACAO DO DOMINIO E DEPLOY WEB

Estado atual:
- Nao existe dominio configurado no projeto.
- Apenas localhost foi encontrado nas configs e documentacao.
- O cliente informou que possui um dominio web que sera usado para site, mas ainda nao confirmou dados tecnicos.

Conclusao:
- E possivel usar o mesmo dominio para site e API, desde que haja controle de DNS.
- Padrao recomendado:
  - Site: https://www.dominio.com.br
  - API: https://api.dominio.com.br

Informacoes que ainda precisam ser confirmadas com o cliente:
- Qual e o dominio.
- Quem controla o DNS.
- Qual hospedagem sera usada.
- Se a hospedagem suporta ASP.NET Core .NET 8.
- Se existe VPS, Docker, Azure App Service ou apenas hospedagem compartilhada.
- Se sera possivel criar subdominio api.dominio.com.br.
- Se o MySQL sera no mesmo servidor, banco gerenciado ou container.

Posicao tecnica:
- Hospedagem comum cPanel/PHP nao deve ser assumida como compativel com esta API.
- Melhor caminho tecnico para a API:
  1. VPS Linux com Nginx + Kestrel + MySQL.
  2. VPS Windows com IIS + ASP.NET Core Hosting Bundle + MySQL.
  3. Azure App Service + Azure Database for MySQL.
  4. Docker em servidor com reverse proxy.
